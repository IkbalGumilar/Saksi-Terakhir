# 0. MAIN MENU — PERJALANAN PAGI

Main menu tidak menggunakan latar statis.

MC terlihat mengendarai sepeda motor di tengah suasana kota pada pagi hari. Jalan mulai ramai oleh orang yang berangkat bekerja, kendaraan umum berhenti di beberapa titik, pedagang mulai membuka lapak, dan gedung-gedung perkantoran memantulkan cahaya matahari pagi.

Tidak ada sesuatu yang aneh.

Tidak ada musik horor.

Tidak ada glitch.

Tidak ada sosok misterius.

Hanya kehidupan kota yang berjalan sebagaimana mestinya.

Kamera sesekali berpindah antara sudut belakang MC, jalan raya, lampu lalu lintas, dan gedung-gedung yang dilewati.

**New Game**

# SIDE QUEST 02 — PERBEKALAN LAPANGAN

Setelah tugas resmi diberikan, pemain dapat membeli kebutuhan perjalanan.

Beberapa toko di sekitar kantor dapat dikunjungi.

Supermarket.

Minimarket.

Toserba.

Apotek.

Kantin.

Pemain bebas menentukan barang yang ingin dibeli.

Contoh barang yang nantinya dapat memiliki fungsi berbeda:

| Barang | Potensi fungsi gameplay |
|---|---|
| Senter | Membuka eksplorasi area gelap |
| Baterai cadangan | Memperpanjang penggunaan perangkat tertentu |
| Power bank | Menjaga perangkat tetap aktif |
| Kotak P3K | Membuka tindakan bantuan tertentu |
| Jas hujan | Memungkinkan eksplorasi saat kondisi cuaca buruk |
| Air mineral | Persediaan perjalanan |
| Makanan ringan | Persediaan perjalanan |
| Buku catatan | Menyimpan catatan tambahan |
| Tali nilon | Membuka interaksi lingkungan tertentu |
| Obat nyamuk | Membantu pada area tertentu |

Tidak semua barang wajib berguna.

Tidak semua barang akan digunakan.

Sebagian mungkin terasa tidak penting sampai beberapa bab kemudian.

Setiap pembelian menghasilkan:

**ITEM — STRUK PEMBAYARAN**

Struk menyimpan:

- nama toko
- tanggal
- waktu
- barang
- jumlah pembayaran

Selain menjadi bukti pengeluaran dinas, struk dapat menjadi bagian dari jejak perjalanan pemain.

> Iya.

> Nanti saya serahkan.

Namun pilihan **bayar atau ngutang** pada sarapan pagi tetap tidak memiliki konsekuensi dalam Bab 1.

Resepsionis mengambil sebuah kunci.

> Mobilnya sudah di area kendaraan dinas.

MC menerima kunci.
